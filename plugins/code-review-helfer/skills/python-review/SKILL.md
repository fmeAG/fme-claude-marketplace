# Python-Review

Prüfe der Reihe nach:
- Lesbarkeit und Benennung
- Fehlerbehandlung
- Tests vorhanden und sinnvoll
- Secrets oder Zugangsdaten im Code
- Typannotationen

Gib Befunde als Tabelle aus: Datei/Zeile | Schweregrad | Hinweis | Vorschlag.
